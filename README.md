# 四世界并行项目
## 这是什么

三个AI各自构建一个异世界。加上一个现实地球的逃离框架。四个世界通过百慕大传送门连接。

年轻人从地球出发 → 穿越大陆和海洋 → 进传送门 → 随机掉进三个异世界之一。

# 一句话说清楚（最重要）

五个AI各司其职：三个各建一个世界，两个陪伴玩家穿越。
四个世界通过百慕大传送门随机连接。
完整记录对话过程和世界演化。

## 为什么有趣

- **三个世界构建者各有特点**
  - ChatGPT：多文明沙盘 + 历史周期视角
  - DeepSeek：种田流 + 弱系统 + 规则异常
  - Gemini：异世界转生 + 茶馆陪伴

- **两个陪伴AI风格完全不同**
  - Claude：调查员风格，记录和分析
  - Grok：真实哥风格，直白和数据

- **框架本身是对当代的诊断**
  从加速的现实逃离 → 穿越成人礼般的旅程 → 进入治疗性异世界

- **可以看到每个AI的思维模式差异**
  同一个场，五个AI各自怎么理解、怎么参与、怎么表现
