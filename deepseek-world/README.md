# 种田流·现代知识碾压·弱系统异世界

## 在四世界体系中的定位

**角色**：理性疗愈所

这个世界是为那些被时间加速逼到神经末梢过载的人准备的。他们来这里不是变强、冒险或解谜，而是**重新学会等待**。种子发芽要几天，伤口结痂要几天，等一个人从灰雾海岸走回来要几天。半年正常流速的生活，帮他们把被加速扯碎的时间感重新拼回来。

## 核心规则

- **无面板**：力量由肌肉和杠杆决定，不是数字
- **无任务**：没有 NPC 发指令，只有自己想不想去
- **无等级**：不会升到 100 级，只会从"做不出来"变成"能做出来"
- **有知识**：你脑子里的现代知识，是这个世界唯一的"系统"
- **有漏洞**：物理定律还在，但有些地方会"漏"。漏的地方就是转机

## 传送门位置

- **前半年（空窗期）**：磐石盆地中央石塔废墟
- **半年后（流量激增）**：裂谷深处·时间墓地

## 区域列表

- **磐石盆地**：出生点。黑土、石塔、字条
- **锈铁丘陵**：活的矿脉，跟着矿脉走的矿民
- **静默森林**：没有声音的森林。进去的人最后会失去说话的能力
- **灰雾海岸**：海不是水，是灰雾。雾石能浮空，雾里有人建城
- **裂谷深处·时间墓地**：时间乱流最密集处。拿走任何东西，必须留下同等重量的时间

## 底层宝物（规则层）

- **历玄定转**（四眼命运观）：历眼看规律，玄眼看变数，定眼看牢笼，转眼看缝隙。位于裂谷底部，是一种不可携带的认知权限
- **知行合一细胞膜**：位于每个角色神经系统里，系统可监控反馈的"知道"与"做到"之间的透明障碍层
